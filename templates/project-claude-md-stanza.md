## Kodi knowledge lives in kodi-drive

Shared Kodi knowledge is **not** in this file. Use the `kodi-drive:*` skills, or read
`<path-to>/kodi-drive/README.md`.

**Do not add generally-useful Kodi findings here.** If you learn something that would
help someone working on a different add-on, it belongs in kodi-drive — contribute it
with `/kodi-drive:contribute` before you finish the session.

This file holds only three things:

- what this project is
- its build, test, and deploy commands
- its local paths

Anything else you are tempted to write here is knowledge someone else needs too.
